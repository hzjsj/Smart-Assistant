# Hermes 执行过程

仅前端展示层变更，不新增接口、依赖或虚构的命令输出。

- `index.tsx` 从原始 SDK 消息按 id 取得请求状态，通过临时展示属性传给过程组件；正文打字机的 `updating` 不驱动展开生命周期，展示属性不写入原始消息或 API 请求。
- 原始请求为 loading/updating 时外层默认展开，结束（成功、失败、停止）时自动收起一次。历史默认收起，结束后可以重新打开。
- 持续流式更新不改变用户手动选择；再次生成该回复才开始新的周期并重置详情选择。
- 工具列表默认可见，调用详情与思考全文分别点击展开。展开状态由过程组件持有，外层折叠卸载内部 DOM 后仍能恢复用户选择。
- 保留真实事件顺序与工具调用 id，关联不明确的思考单独显示。已有进度消息可展示，完整 Shell 命令/输出无字段时不伪造。
- 错误、警告、审批、最终正文及题库卡片在过程折叠区域之外。工具失败或停止不因后续普通进度或请求结束变为成功，完成后的进度条不再运行。
- 使用白底、灰色说明、14/22 标题、13/22 详情和浅灰详情区域；容器查询适配窄分栏，避免固定卡片宽度。

验证：Hermes 前端 10 个套件共 69 项通过。独立 HTTP/SSE 浏览器夹具覆盖默认展开、两层详情收起、手动操作保持、请求先于正文打字结束、重试、失败、停止、后台可见性模拟及完整/窄分栏/手机布局。既有组卷浏览器测试回归选题、标题编辑、打印和 Word/PDF/Excel/JSON 下载。

在前端根目录运行：

```powershell
node src/pages/hermes/components/process/tests/process.e2e.cjs
```

默认连接前端 `http://localhost:8000`，可用 `HERMES_TEST_FRONTEND_URL` 修改。模拟 API 完全由测试启动的临时本地 HTTP 服务提供，不请求真实模型或后端。截图写入 Hermes 内已忽略的 `.artifacts/`。当前无头浏览器未提供真实后台状态，测试通过模拟 visibilitychange 检查后台完成。
